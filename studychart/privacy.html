基本方針

行政書士 過去問 条文判例完備（以下「本アプリ」）は、行政書士試験の学習アプリです。学習の記録は端末内にのみ保存します。AI機能を使うときだけ、質問の内容を外部のサーバーへ送信します。それ以外の通信は行いません。

アカウント登録は不要です。氏名・メールアドレス・電話番号などの個人を特定する情報は、一切お預かりしません。

端末内にのみ保存するもの

  • 問題の解答履歴、正誤、ブックマーク、学習の進み具合
  • AI機能の残り利用回数
  • 端末を識別するための符号（インストール時に自動生成されるランダムな文字列）

これらは外部へ送信しません。アプリを削除すると端末内のデータは削除されます。

AI機能を使うときに送信するもの

本アプリのAI機能（質問への回答、記述式答案の採点）を実行したときに限り、次の情報を送信します。

送信するもの送信先目的
入力された質問文（最大1,000字）当方が運営する中継サーバー（Cloudflare Workers）を経由し、Google の Gemini API へ送信します。回答および採点結果の生成
入力された記述式の答案（最大500字）
該当する条文・判例の本文（アプリに収録されているもの）
同一問題内での直前のやり取り（最大8往復）
端末を識別するための符号中継サーバー1台あたりの利用回数を制限し、不正利用を防ぐため

質問文にご自身の氏名や連絡先などを書かないでください。入力された文章はそのまま送信されます。

中継サーバーでの取り扱い

  • 質問文・答案・回答の内容は保存しません。処理が終わり次第、破棄されます。
  • 利用回数の制限のため、端末を識別する符号とIPアドレスを、それぞれ1日および1時間だけ回数の集計に用います。期限が過ぎると自動的に消去されます。
  • 送信先である Google の Gemini API における取り扱いは、同社の定めに従います。

広告と解析

広告は表示しません。広告・解析目的のトラッキングSDKは一切組み込んでいません。行動履歴の収集や第三者への提供は行いません。

購入について

アプリ内課金の決済はすべてApple社が行います。本アプリがクレジットカード情報等をお預かりすることはありません。

データの削除

アプリを削除すると、端末内の学習記録および識別用の符号は削除されます。中継サーバーには内容を保存していないため、削除のお手続きは不要です。
